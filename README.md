# Python Bank System

A console-based banking application built in Python using Object-Oriented Programming (OOP) and JSON persistence.

## Features

Account Management
- Create an account
- Login
- Exit the application

Banking Operations

When an account is logged in, you can:

- Deposit money
- Withdraw money
- Transfer money
- Check balance
- Check transactions history
- Add interst
- logout
- Exit the application

## Accounts type

The application currently supports:

Normal Account
- Deposit
- Withdraw
- Transfer
- Transaction history

Saving Account
- Inherits from Account
- Has an interest rate
- Can earn interest
- Has a maximum withdrawal limit of 500

Checking Account
- Inherits from Account
- Has a transaction fee
